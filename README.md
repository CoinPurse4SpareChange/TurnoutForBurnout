# The Cost of Caring Without Control

An educator-centered research resource about autonomy, disempowerment, institutional risk, moral distress, and burnout.

## Publish on GitHub Pages
1. Create a new GitHub repository (e.g. `caring-without-control`).
2. Upload **the contents** of this folder to the repository root (`index.html` must be at the root).
3. Commit the files to the `main` branch.
4. Navigate to Settings → Pages → Build and deployment → Deploy from a branch.
5. Select `main` and `/(root)`, then Save.
6. The site will be available at `https://YOURUSERNAME.github.io/caring-without-control/` after GitHub publishes it.

For a private prototype, keep local files offline; a GitHub Pages site is publicly available once published.

No JavaScript framework, build step, or analytics. Content can be edited directly in HTML. This v0.1 is a functional editorial prototype rather than a completed systematic literature review.
